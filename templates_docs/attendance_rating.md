# Рейтинг посещаемости мероприятий (attendance_rating.html) - переход из "Календарь мероприятий"

## Назначение
Статистика посещаемости мероприятий студентами. Показывает кто сколько мероприятий посетил, рейтинг активности.

## Доступ
- **Требуемое право:** `manage_events`
- **Ссылка:** Из календаря мероприятий → "Рейтинг посещаемости"

## Что можно делать

### Просмотр рейтинга
На странице отображается таблица со студентами:
- **Студент** - ФИО
- **Группа** - учебная группа
- **Количество посещений** - сколько мероприятий посетил
- **Рейтинг** - место в рейтинге
- **Комната** - в какой комнате проживает студент

### Фильтрация данных
Можно отфильтровать по:
- **Периоду** - выберите период 
- **Мероприятию** - статистика по конкретному мероприятию (в карточке мероприятия)

## Как считается рейтинг

1. Система считает сколько мероприятий посетил каждый студент
2. Сортирует по количеству посещений
3. Присваивает места в рейтинге

## Важные моменты

- Рейтинг обновляется автоматически при регистрации на мероприятия
- Показывается актуальная статистика
- Можно фильтровать по датам
- Полезно для мониторинга активности студентов
