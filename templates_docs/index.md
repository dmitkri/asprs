# Главная страница (index.html)

## Назначение
Публичная страница для просмотра информации о студентах. Позволяет искать студентов и просматривать их карточки без авторизации.

## Доступ
- **Доступ:** Все (публичная страница)
- **Ссылка** `/`

## Что на странице

### Поиск студентов
- **Поле поиска** - можно искать студентов по всем полям (ФИО, группа, комната и т.д.)
- Результаты обновляются автоматически при вводе

### Таблица студентов
- Отображает список всех студентов
- Показывает основные данные (ФИО, группа, комната и другие поля)

### Просмотр карточки студента
- Кликните на студента в таблице
- Откроется модальное окно с полной информацией о студенте
- Можно просмотреть все данные студента

### Вход в систему
- Кнопка "Вход" в правом верхнем углу
- Переход на страницу авторизации `/admin`

## Как использовать

### Поиск студента
1. Откройте главную страницу
2. Введите в поле поиска ФИО, группу или другую информацию
3. Таблица автоматически отфильтруется
4. Найдите нужного студента

### Просмотр карточки студента
1. Найдите студента в таблице
2. Кликните на строку со студентом
3. Откроется модальное окно с полной информацией
4. Просмотрите данные студента

### Вход в админ-панель
1. Нажмите кнопку "Вход" в правом верхнем углу
2. Или перейдите на `/admin`
3. Введите логин и пароль
4. Войдите в систему

## Важные моменты

- Служит для быстрого поиска и просмотра информации о студентах
- Для редактирования данных нужно войти в админ-панель
