# Профиль администратора (admin_profile.html)

## Назначение
Личные настройки администратора. Можно изменить пароль, посмотреть свою роль, обновить данные.

## Доступ
- **Требуемое право:** Авторизация (доступно всем авторизованным)
- **Ссылка:** В меню администратора → "Профиль"

## Что можно делать

### Просмотр информации о себе
На странице отображается:
- **Логин** - имя для входа в систему
- **ФИО** - Ваше полное имя
- **Роль** - Ваша роль в системе (admin, vospitatel и т.д.)

### Смена пароля
1. Найдите раздел "Смена пароля"
2. Введите текущий пароль
3. Введите новый пароль (минимум 6 символов)
4. Подтвердите новый пароль (введите еще раз)
5. Нажмите "Изменить пароль"
6. Пароль будет изменен

**Важно:**
- При первом входе возможна смена пароля
- Новый пароль должен быть надежным
- После смены пароля нужно войти заново

## Важные моменты

- Пароль хранится в зашифрованном виде
- При смене пароля нужно войти заново
- Роль нельзя изменить самому (только супер-администратор)
- Профиль доступен всем авторизованным пользователям
