# Telegram бот для студентов

## Что это такое

Telegram бот - это помощник для студентов, который работает прямо в Telegram. Через бота можно получить QR-коды, оплатить проживание, подать заявку на ремонт и многое другое.

## Как начать пользоваться

### Первая регистрация

1. Найдите бота в Telegram (имя бота указывает администратор)
2. Нажмите кнопку "Старт" или отправьте команду `/start`
3. Бот спросит у Вас данные для регистрации:
   - Если Вы **обычный студент** (живете в общежитии):
     - Номер корпуса
     - Номер подъезда
     - Номер комнаты
     - ФИО (полное имя)
     - Номер телефона
   - Если Вы **местный студент** (не живете в общежитии):
     - Нажмите кнопку "Я местный!" в начале регистрации
     - Укажите только ФИО и номер телефона

4. После регистрации откроется главное меню с кнопками

## Команды бота

### `/start` - Начать работу
- Запускает бота или возвращает в главное меню
- Если Вы еще не зарегистрированы, начнется процесс регистрации
- Если уже зарегистрированы, откроется главное меню

### `/menu` - Главное меню
- Показывает все доступные функции
- Можно вернуться в меню в любой момент

### `/qr` - Получить QR-код для белья
- Быстрый способ получить QR-код для получения постельного белья
- Работает только если есть активный период выдачи белья

### `/event` - Работа с мероприятиями
- Показывает информацию о мероприятиях

## Что можно делать через бота

### Для всех студентов

#### 1. Получить QR-код для белья
- **Как:** Нажмите "Получить QR-код для белья" в меню
- **Что происходит:** Бот создает QR-код, который действителен 5 минут
- **Когда можно:** Только в период выдачи белья (устанавливает администратор)
- **Важно:** 
  - QR-код можно получить только один раз за период
  - Если уже получил белье в этом периоде, нужно ждать следующего периода
  - Покажи QR-код администратору для сканирования

#### 2. Получить QR-код для мероприятий
- **Как:** Нажмите "Мой QR-код для мероприятий" в меню
- **Что происходит:** Бот создает персональный QR-код
- **Зачем:** Покажи этот QR-код организатору мероприятия, он отсканирует его и зарегистрирует тебя
- **Важно:** QR-код содержит ссылку на бота, при сканировании откроется форма регистрации

#### 3. Оплатить проживание
- **Как:** Нажмите "Оплатить проживание" в меню
- **Что происходит:** Бот создает QR-код для оплаты через банковское приложение
- **Как оплатить:**
  1. Откройте приложение своего банка (Сбербанк онлайн, ТБанк и т.д.)
  2. Найдите функцию "Оплата по QR-коду" или "Сканировать QR"
  3. Отсканируйте QR-код из бота или вставьте его
  4. Проверьте данные и подтвердите оплату
- **Важно:** 
  - Сумма рассчитывается автоматически
  - После оплаты администратор-аудит проверит платеж в системе

#### 4. Подать заявку на ремонт
- **Как:** Нажмите "Подать заявку" в меню
- **Что происходит:** Бот попросит описать проблему
- **Что написать:** Опишите что сломалось или что нужно сделать (например: "Протекает кран в раковине", "Не работает розетка", "Нужна уборка в комнате")
- **Что дальше:** Заявка попадет администратору, он рассмотрит ее и свяжется с Вами

#### 5. Посмотреть свои заявки
- **Как:** Нажмите "Мои заявки" в меню
- **Что показывается:** Список всех твоих заявок с их статусами:
  - **Новая** - заявка только что создана
  - **В работе** - администратор взял заявку в работу
  - **Выполнена** - заявка закрыта
- **Можно увидеть:** Номер заявки, описание, статус

### Для организаторов мероприятий

Если Вы организатор мероприятия (добавлены администратором):

#### Сканировать QR на мероприятии
- **Как:** Нажмите "Сканировать QR на мероприятии" в меню
- **Что происходит:** 
  1. Выберите мероприятие из списка
  2. Отсканируйте QR-код студента (или введите код вручную)
  3. Студент автоматически зарегистрируется на мероприятие
- **Важно:** 
  - Нужно иметь username в Telegram
  - Можно сканировать QR-коды всех мероприяттй

### Для старост подъезда

Если Вы староста подъезда (назначены администратором):

#### График дежурств
- **Как:** Нажмите "График дежурств" в меню
- **Что можно:**
  - Посмотреть график дежурств для своего подъезда
  - Сгенерировать график на текущий месяц
  - Сгенерировать график на следующий месяц
- **Что такое график:** Excel файл с расписанием, кто и когда дежурит в общественных зонах

### Для ответственных за обходы

Если Вы назначены ответственным за обходы:

#### Назначить на обход
- **Как:** Нажмите "Назначить на обход" в меню
- **Что можно:**
  1. Выбрать студента из списка
  2. Выбрать корпус и подъезд для обхода
  3. Студент получит задание на обход

## Особенности для местных студентов

Если Вы местный студент (не живете в общежитии):

- При регистрации нажмите "Я местный!" - не нужно указывать корпус, подъезд и комнату
- В главном меню доступна только одна функция: "Мой QR-код для мероприятий"
- Нельзя получить QR для белья, оплатить проживание или подать заявку (эти функции только для проживающих в средстве размещения)

## Как работает регистрация на мероприятие через QR

1. Студент получает свой QR-код для мероприятий в боте
2. На мероприятии показывает QR-код организатору
3. Организатор сканирует QR-код через бота
4. Открывается форма выбора мероприятия
5. Организатор выбирает мероприятие
6. Студент автоматически регистрируется на мероприятие
7. Посещаемость сохраняется в системе

## Боковое меню в Telegram

В Telegram есть боковое меню с командами бота:
- `/menu` - Главное меню
- Другие команды могут быть добавлены администратором

Это меню появляется автоматически, когда Вы начинаете писать боту.
