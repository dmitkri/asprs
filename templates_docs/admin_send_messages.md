# Отправка сообщений (admin_send_messages.html)

## Назначение
Массовая рассылка сообщений студентам через Telegram. Можно отправить сообщение определенной группе студентов.

## Доступ
- **Требуемое право:** `manage_send_messages`
- **Ссылка:** В меню администратора → "Отправка сообщений"

## Что можно делать

### Выбор получателей
Можно выбрать кому отправить сообщение:
- **Всем студентам** - сообщение получит каждый зарегистрированный студент
- **Выбранным студентам** - выберите конкретных студентов из списка
- **Студентам, которые не получили постельное белье за прошедший период** - система определяет автоматически

### Создание сообщения
1. Выберите получателей
2. Введите текст сообщения
3. Нажмите "Отправить"

### Использование шаблонов
Если есть сохраненные шаблоны:
1. Выберите шаблон из списка
2. Текст автоматически заполнится
3. Можете изменить текст перед отправкой
4. Отправьте

### Индивидуальное сообщение
1. Выберите "Выбранные студенты"
2. Найдите нужных студентов через поиск
3. Отметьте галочками
4. Введите текст сообщения
5. Отправьте

## Важные моменты

- Сообщения отправляются через Telegram user bot
- Можно сохранить текст как шаблон для повторного использования
- Статус доставки показывается после отправки
- Можно увидеть сколько сообщений отправлено успешно
