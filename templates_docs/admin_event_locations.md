# Управление местами проведения мероприятий (admin_event_locations.html)

## Назначение
Управление списком мест, где могут проводиться мероприятия. Позволяет добавлять новые места, редактировать существующие.

## Доступ
- **Требуемое право:** `manage_events`
- **Ссылка:** В меню администратора → "Места проведения мероприятий"

## Что можно делать

### Добавление нового места
1. В форме "Добавить место" введите:
   - **Название места** (обязательно) - например: "Коворкинг 'Псоу'"
   - **Описание** (необязательно) - дополнительная информация о месте
2. Нажмите кнопку "Добавить место"
3. Место появится в списке и станет доступным для выбора при создании мероприятия

### Редактирование места
1. В таблице найдите нужное место
2. Нажмите кнопку "Редактировать"
3. В открывшемся окне измените:
   - Название места
   - Описание
   - Статус активности (чекбокс "Активно")
4. Нажмите "Сохранить"

### Активация/деактивация места
- **Деактивация:** Нажмите "Деактивировать" - место скроется из списка при создании мероприятия, но останется в базе
- **Активация:** Нажмите "Активировать" - место снова станет доступным

## Важные моменты

- Если место используется в существующих мероприятиях, его нельзя удалить - только деактивировать
- Деактивированные места не отображаются в выпадающем списке при создании мероприятия
- Активные места отображаются в списке при создании нового мероприятия в календаре

## Как это работает

1. При создании мероприятия в календаре доступны только активные места
2. Если место деактивировано, оно не показывается в списке, но остается в базе данных
