# Организаторы мероприятий (admin_event_organizers.html)

## Назначение
Управление списком организаторов мероприятий. Организаторы могут сканировать QR-коды студентов на мероприятиях через Telegram бота.

## Доступ
- **Требуемое право:** `manage_events`
- **Ссылка:** В меню администратора → "Организаторы мероприятий"

## Что можно делать

### Просмотр списка организаторов
На странице отображается таблица со всеми организаторами:
- **Telegram username** - имя пользователя в Telegram
- **ФИО** - полное имя организатора
- **Дата добавления** - когда был добавлен
- **Действия** - кнопки для удаления

### Добавление организатора
1. В форме "Добавить организатора" введите Telegram username
2. Username должен быть без символа @ (например: `ivanov`, а не `@ivanov`)
3. Нажмите "Добавить"
4. Организатор появится в списке

**Важно:**
- Username должен существовать в Telegram
- Организатор должен иметь username (нельзя добавить без username)
- После добавления организатор сможет сканировать QR-коды через бота

### Удаление организатора
1. Найдите организатора в таблице
2. Нажмите "Удалить"
3. Подтвердите удаление
4. Организатор больше не сможет сканировать QR-коды

## Как это работает

1. **Администратор добавляет организатора** - указывает Telegram username
2. **Организатор открывает бота** - находит своего бота в Telegram
3. **В меню появляется функция** - "Сканировать QR на мероприятии"
4. **Организатор сканирует QR** - студент автоматически регистрируется на мероприятие

## Примеры работы

### Добавление организатора
1. Узнайте Telegram username организатора (например: `petrov_ivan`)
2. В форме введите: `petrov_ivan` (без @)
3. Нажмите "Добавить"
4. Организатор добавлен

### Проверка организатора
1. Попросите организатора открыть бота
2. В меню должна быть кнопка "Сканировать QR на мероприятии"
3. Если кнопки нет - проверьте username

## Важные моменты

- Организатор должен иметь username в Telegram
- Username вводится без символа @
- После добавления изменения применяются сразу
- Организатор может сканировать QR-коды для всех мероприятий (глобальный организатор)
- Или только для мероприятий, где он указан как организатор
