# Графики дежурств (admin_duty_schedules.html)

## Назначение
Просмотр графиков дежурств студентов по комнатам.

## Доступ
- **Требуемое право:** `manage_rooms`
- **Ссылка:** В меню администратора → "Графики дежурств"

## Что можно делать

### Просмотр графиков
На странице можно увидеть:
- Список созданных графиков
- Для какого корпуса и подъезда график
- За какой месяц и год
- Кто создал график
