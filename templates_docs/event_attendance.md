# Посещаемость мероприятия (event_attendance.html)

## Назначение
Просмотр списка всех студентов, зарегистрированных на конкретное мероприятие. Показывает кто пришел, когда зарегистрировался, и другую информацию.

## Доступ
- **Требуемое право:** `manage_events`
- **Ссылка:** Из календаря мероприятий → клик на мероприятие → "Посещаемость"

## Что можно делать

### Просмотр списка участников
На странице отображается таблица со всеми зарегистрированными студентами:
- **ФИО** - полное имя студента
- **Группа** - учебная группа
- **Комната** - номер проживания студента
- **Время регистрации** - когда был отмечен
- **Кто зарегистрировал** - username организатора

## Как это работает

1. **Студенты регистрируются** - через сканирование QR-кодов
2. **Данные сохраняются** - в базу данных
3. **Список обновляется** - автоматически при новых регистрациях

## Важные моменты

- Список обновляется в реальном времени
- Показывается время регистрации каждого студента
- Можно увидеть кто зарегистрировал студента
