# Управление проживанием (admin_manage_accommodation.html)

## Назначение
Страница предназначена для **аудита оплат проживания**. Позволяет просматривать кто оплатил проживание, а кто нет, и рассылать напоминания студентам, которые не оплатили.

## Доступ
- **Требуемое право:** `manage_rooms`
- **Ссылка:** В меню администратора → "Управление проживанием"

## Что можно делать

### Просмотр статуса оплаты по комнатам
На странице отображается таблица со всеми комнатами:
- **Комната** - корпус, подъезд, номер комнаты
- **Вместимость** - сколько человек может жить в комнате
- **Проживает** - сколько студентов сейчас живет
- **Оплатили** - сколько студентов оплатили проживание (отображается при выборе месяца)
- **Не оплатили** - сколько студентов не оплатили (отображается при выборе месяца)
- **Список студентов** - список всех проживающих с указанием статуса оплаты
- **Действия** - кнопка для отправки напоминаний

### Выбор периода для проверки оплаты
1. В поле "Месяц оплаты" выберите месяц и год (формат: ММ.ГГГГ)
2. Нажмите "Обновить"
3. Таблица обновится и покажет статус оплаты за выбранный период

### Просмотр детальной информации
Для каждой комнаты отображается:
- Список всех проживающих студентов
- Статус оплаты каждого студента (оплатил/не оплатил)
- Количество оплативших и не оплативших

### Отправка напоминаний об оплате
1. Выберите месяц для проверки оплаты
2. Найдите комнату, где есть неоплатившие студенты
3. Нажмите кнопку "Напоминания" в колонке "Действия"
4. Подтвердите отправку
5. Всем неоплатившим студентам в этой комнате будет отправлено напоминание через Telegram бота

**Важно:**
- Напоминания отправляются только студентам, которые зарегистрированы в Telegram боте
- Если студент не зарегистрирован в боте, напоминание не будет отправлено
- После отправки появится сообщение о количестве успешно отправленных и ошибок

### Поиск комнат
Можно найти комнату по:
- Номеру корпуса
- Номеру подъезда
- Номеру комнаты

Введите данные в поле поиска, и таблица автоматически отфильтруется.

## Как это работает

1. **Выбираете месяц** - указываете период, за который нужно проверить оплату
2. **Система проверяет оплаты** - для каждой комнаты проверяется, кто из проживающих оплатил за выбранный период
3. **Отображается статистика** - видно сколько студентов оплатили, а сколько нет
4. **Отправляете напоминания** - нажимаете кнопку "Напоминания" для комнат с неоплатившими студентами
5. **Студенты получают сообщения** - напоминания отправляются через Telegram бота

## Важные моменты

- Страница предназначена для аудита и контроля оплат, а не для размещения студентов
- Для размещения студентов используйте страницу "Управление студентами" (главная страница админ-панели)
- Напоминания отправляются только зарегистрированным в боте студентам
- Статус оплаты проверяется на основе данных из раздела "Управление оплатами"
- Если месяц не выбран, отображается только информация о комнатах без статуса оплаты
- Можно отправлять напоминания только для комнат, где есть неоплатившие студенты
