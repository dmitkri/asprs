# Панель администратора (admin.html)

## Назначение
Главная страница системы - рабочий стол администратора. Здесь можно просматривать всех студентов, искать, фильтровать, редактировать данные и переходить в другие разделы системы.

## Доступ
- **Требуемое право:** Авторизация (доступно всем авторизованным)
- **Ссылка** `/admin_panel` или `/admin`

## Что можно делать

### Просмотр списка студентов
На главной странице отображается таблица со всеми студентами:
- **ФИО** - полное имя студента
- **Телефон** - номер телефона
- **Группа** - учебная группа
- **Рейтинг** - заполненность карточки студента
- **Возраст** - возраст студента

### Поиск студентов
1. Введите текст в поле поиска
2. Система найдет студентов по:
   - ФИО
   - Телефону
   - Группе
3. Результаты обновляются автоматически

### Фильтрация студентов
Можно отфильтровать список по:
- **Статусу проживания** - все, проживающие, не проживающие
- **Здоровью** - все, здоровые, с проблемами

### Просмотр карточки студента
1. Кликните на строку студента в таблице
2. Откроется модальное окно с полной информацией:
   - Личные данные
   - Контакты
   - Информация о проживании
   - Заметки
   - История изменений
   - И другое

### Редактирование студента
1. Откройте карточку студента
2. Нажмите "Редактировать" (если есть право `edit`)
3. Измените нужные данные
4. Сохраните изменения

### Добавление студента
1. Нажмите кнопку "Добавить студента" в боковом меню (если есть право `edit`)
2. Заполните форму:
   - ФИО
   - Телефон
   - Группа
   - Комната (корпус, подъезд, номер)
   - Другие данные
3. Сохраните

### Добавление нового блока в карточку студента
1. Введите название блока
2. Укажите тип данных (Текст, число, чекбокс, дата)
3. Нажмите "Добавить"
4. Новый блок будет добавлен всем студентам

### Импорт студентов из Excel
1. Нажмите "Импорт Excel" в боковом меню (если есть право `import`)
2. Выберите Excel файл
3. Нажмите "Импортировать"
4. Студенты будут добавлены в базу

### Переход в другие разделы
В боковом меню доступны ссылки на:
- Экспорт данных
- Управление администраторами
- Управление ролями
- Управление группами
- Управление бельем
- Календарь мероприятий
- Управление комнатами
- И другие разделы (зависит от прав)

## Модальные окна

На странице используются модальные окна для:
- **Редактирование студента** - открывается при клике на студента
- **Импорт Excel** - форма загрузки файла
- **История изменений** - показывает кто и когда менял данные (находится в карточке студента)
- **Смена пароля** - при первом входе или по запросу

## Как пользоваться

### Навигация
- **Боковое меню** - слева, содержит ссылки на все разделы
- **Поиск** - в верхней части таблицы

### Работа с таблицей
1. Используйте поиск для быстрого поиска студентов
2. Используйте фильтры для сужения списка
3. Кликните на строку студента для просмотра карточки
4. В карточке можно редактировать данные

### Импорт данных
1. Нажмите "Импорт Excel" в меню
2. Выберите файл с данными студентов
3. Нажмите "Импортировать"
4. Дождитесь завершения импорта

## Важные моменты

- Набор функций зависит от роли и прав
- Таблица студентов обновляется автоматически
- История изменений сохраняется для каждого студента
- Загрузочный экран показывается при загрузке страницы
