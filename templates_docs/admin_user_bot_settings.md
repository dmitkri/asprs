# Настройки User Bot (admin_user_bot_settings.html)

## Назначение
Настройка Telegram User Bot для отправки сообщений от аккаунта. User Bot позволяет отправлять сообщения студентам через Telegram (не через бота).

## Доступ
- **Требуемое право:** `manage_admins`
- **Ссылка:** В меню администратора → "Настройка User Bot"

## Что можно делать

### Настройка User Bot
1. Получите данные для User Bot:
   - **API ID** - получите на [my.telegram.org](https://my.telegram.org)
   - **API Hash** - получите на [my.telegram.org](https://my.telegram.org)
   - **Номер телефона** - номер телефона для авторизации
2. Введите данные в форму
3. Нажмите "Сохранить"
4. Нажмите "Подключить" для авторизации

### Проверка подключения
1. Нажмите "Проверить подключение"
2. Система проверит, работает ли User Bot
3. Если все хорошо - увидите сообщение об успехе
4. Если есть проблемы - увидите ошибку

### Отключение User Bot
1. Нажмите "Отключить"
2. User Bot будет отключен
3. Сообщения через User Bot перестанут работать

## Как получить API ID и API Hash

1. Перейдите на [my.telegram.org](https://my.telegram.org)
2. Войдите со своим номером телефона
3. Перейдите в раздел "API development tools"
4. Создайте приложение (укажите название, платформу)
5. Скопируйте API ID и API Hash

## Важные моменты

- User Bot нужен для отправки сообщений студентам
- Требует авторизацию через номер телефона
- Данные хранятся в зашифрованном виде
- После настройки можно отправлять сообщения через систему
