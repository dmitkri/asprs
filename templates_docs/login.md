# Вход в систему (login.html)

## Назначение
Страница для входа администраторов в систему. Требует логин и пароль для доступа к админ-панели.

## Доступ
- **Доступ:** Все (публичная страница)
- **Ссылка** `/admin` или `/admin/login`

## Как войти

### Стандартные данные для первого входа
- **Логин:** `admin`
- **Пароль:** `admin123`

**Важно:** При первом входе система потребует сменить пароль!

### Процесс входа
1. Откройте страницу входа
2. Введите логин (имя пользователя)
3. Введите пароль
4. Нажмите "Войти"
5. Если данные правильные - попадете в админ-панель
6. Если неправильные - появится сообщение об ошибке

### Ошибки при входе
Если не получается войти:
- **"Неверный логин или пароль"** - проверьте правильность данных
- **"Пользователь не найден"** - проверьте логин

### Смена пароля при первом входе
1. Войдите с паролем `admin123`
2. Появится окно "Смените пароль"
3. Введите текущий пароль: `admin123`
4. Введите новый пароль (минимум 6 символов)
5. Подтвердите новый пароль
6. Нажмите "Изменить"
7. Войдите с новым паролем

## Важные моменты

- Пароли хранятся в зашифрованном виде
- Кнопка "Назад" возвращает на главную страницу
- После входа создается сессия, которая сохраняется пока не выйдете
