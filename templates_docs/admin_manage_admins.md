# Управление администраторами (admin_manage_admins.html)

## Назначение
Создание новых администраторов, редактирование существующих, управление их ролями и статусами. Только для супер-администраторов.

## Доступ
- **Требуемое право:** `manage_admins`
- **Ссылка:** В меню администратора → "Управление администраторами"

## Что можно делать

### Просмотр списка администраторов
На странице отображается таблица со всеми администраторами:
- **ID** - уникальный номер
- **Логин** - имя для входа в систему
- **ФИО** - полное имя администратора
- **Роль** - роль в системе (admin, vospitatel, и т.д.)
- **Статус** - активен или заблокирован
- **Дата создания** - когда был создан аккаунт
- **Действия** - кнопки для редактирования или удаления

### Добавление нового администратора
1. Нажмите кнопку "Добавить администратора"
2. Заполните форму:
   - **Логин** - уникальное имя для входа (например: ivanov_admin)
   - **Пароль** - пароль для входа (минимум 6 символов)
   - **ФИО** - полное имя администратора
   - **Роль** - выберите роль из списка (admin, vospitatel, audit, razmeshenie и т.д.)
3. Нажмите "Добавить"
4. Администратор появится в списке

**Важно:** 
- Логин должен быть уникальным
- При первом входе администратору будет предложено сменить пароль

### Редактирование администратора
1. В таблице найдите нужного администратора
2. Нажмите кнопку "Редактировать"
3. В открывшемся окне можно изменить:
   - **ФИО** - имя администратора
   - **Роль** - изменить роль
   - **Пароль** - установить новый пароль (необязательно, оставьте пустым если не нужно менять)
   - **Активен** - включить/выключить доступ
4. Нажмите "Сохранить"

### Удаление администратора
1. Найдите администратора в таблице
2. Нажмите кнопку "Удалить"
3. Подтвердите удаление

**Важно:** 
- Нельзя удалить самого себя
- Удаление необратимо

## Роли администраторов

При создании или редактировании можно выбрать роль:
- **super_admin** - полный доступ ко всему
- **admin** - доступ ко всему кроме управления администраторами
- **vospitatel** - воспитатель, может работать со студентами, бельем, мероприятиями
- **audit** - только раздел оплат
- И другие...

## Важные моменты

- Только super_admin может управлять администраторами
- При создании администратора автоматически создается запись в базе
- Пароли хранятся в зашифрованном виде
- Можно изменить пароль администратора, если он забыл
