# Календарь мероприятий (events_calendar.html)

## Назначение
Планирование, создание и управление мероприятиями для студентов. Позволяет создавать события, отслеживать посещаемость и управлять организаторами.

## Доступ
- **Требуемое право:** `manage_events`

## Что можно делать

### Просмотр календаря
- Календарь отображает все мероприятия по месяцам
- Прошедшие мероприятия отображаются серым цветом
- Запланированные мероприятия отображаются фиолетовым цветом
- Клик по мероприятию открывает детальную информацию

### Создание мероприятия
1. Нажмите кнопку "Добавить мероприятие" в верхнем меню
2. Заполните форму:
   - **Место проведения** - выберите из списка (можно добавить новое место через "Места проведения" в меню)
   - **Мероприятие** - описание мероприятия
   - **Дата** - выберите дату проведения
   - **Время** - укажите время начала
   - **Организатор** - система автоматически привязывает мероприятие к учетной записи воспитателя который создал его
   - **Соавтор** - можно добавить дополнительного организатора (необязательно)
3. Нажмите "Создать мероприятие"

### Просмотр участников
1. Кликните на мероприятие в календаре
2. В открывшемся окне будет показан список зарегистрированных студентов
3. Можно увидеть количество участников в правом верхнем углу таблицы

### Удаление мероприятия
1. Кликните на мероприятие в календаре
2. Нажмите "Удалить мероприятие"
3. Подтвердите удаление

## Дополнительные функции

### Рейтинг посещаемости
- Кнопка "Рейтинг посещаемости" в верхнем меню
- Показывает статистику посещаемости мероприятий студентами

### Места проведения
- Кнопка "Места проведения" в меню администратора
- Позволяет добавлять, редактировать и управлять местами проведения мероприятий

## Особенности
- Места проведения можно добавлять через отдельную страницу управления
- Прошедшие мероприятия автоматически определяются по дате и времени
- Можно добавлять соавторов для совместной организации мероприятия
- Все мероприятия сохраняются в базе данных и доступны для просмотра в календаре
