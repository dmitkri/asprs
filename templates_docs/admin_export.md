# Экспорт данных (admin_export.html)

## Назначение
Выгрузка данных студентов в Excel файл. Можно экспортировать студентов по разным критериям (подъезд, группа, возраст).

## Доступ
- **Требуемое право:** `view`
- **Ссылка:** В меню администратора → "Экспорт"

## Как использовать

### Шаг 1: Выберите тип экспорта
В выпадающем списке "Тип экспорта" выберите один из вариантов:
- **Список проживающих в подъезде** - экспортирует всех студентов из конкретного подъезда
- **Список группы** - экспортирует всех студентов из выбранной группы
- **Список совершеннолетних** - экспортирует всех совершеннолетних студентов
- **Список несовершеннолетних** - экспортирует всех несовершеннолетних студентов

### Шаг 2: Укажите параметры
В зависимости от выбранного типа появятся дополнительные поля:

**Для подъезда:**
- Выберите корпус и подъезд из списка

**Для группы:**
- Выберите группу из списка

**Для совершеннолетних/несовершеннолетних:**
- Дополнительных параметров не требуется

### Шаг 3: Экспортируйте
1. Нажмите кнопку "Экспортировать в Excel"
2. Подождите пока файл создается (появится индикатор загрузки)
3. Файл автоматически начнет скачиваться
4. Откройте файл в Excel или другом редакторе

## Что происходит при экспорте

1. Система находит всех студентов по выбранным критериям
2. Фильтрует данные по выбранным столбцам
3. Создает Excel файл с данными
4. Файл автоматически скачивается

## Важные моменты

- Файл создается в формате .xlsx (Excel)
- Если студентов много, экспорт может занять время
- Кнопка блокируется на время создания файла
- После экспорта появится сообщение об успехе или ошибке
