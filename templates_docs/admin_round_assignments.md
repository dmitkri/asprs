# Назначение на обход (admin_round_assignments.html)

## Назначение
Назначение студентов на обходы комнат. Обходы нужны для проверки соблюдения ПВР для несовершеннолетних студентов.

## Доступ
- **Требуемое право:** `manage_round_assignments`
- **Ссылка:** В меню администратора → "Назначение на обход"

## Что можно делать

На странице есть три раздела:
1. **Старшие студенты** - назначение старших студентов (Руководители обходных)
2. **Старосты подъездов** - назначение старост подъездов
3. **Назначения на подъезды** - назначение студентов на обходы (обходные)

### Назначение старшего студента

**Важно:** Назначение старших студентов доступно только суперадмину.

1. Найдите раздел "Старшие студенты"
2. Нажмите "Назначить старшего"
3. Введите ФИО студента в поле поиска
4. Выберите студента из списка
5. Статус старшего студента будет установлен

**Что может делать старший студент:**
- Назначать студентов на обходы через Telegram бота (кнопка "Назначить на обход")
- Выбирать студента и корпус-подъезд для назначения
- Назначения сохраняются в системе

**Снятие статуса старшего студента:**
1. Найдите старшего студента в списке
2. Нажмите "Удалить" рядом с его именем
3. Статус будет снят

### Назначение старосты подъезда

**Важно:** Назначение старост подъездов доступно только суперадмину.

1. Найдите раздел "Старосты подъездов"
2. Нажмите "Назначить старосту"
3. Введите ФИО студента в поле поиска
4. Выберите студента из списка
5. Укажите корпус и подъезд, за который он будет отвечать
6. Нажмите "Назначить"

**Что может делать староста подъезда:**
- Генерировать график дежурств для своего подъезда через Telegram бота

**Снятие статуса старосты:**
1. Найдите старосту в списке
2. Нажмите "Удалить" рядом с его именем
3. Статус будет снят, назначение на подъезд удалено

### Просмотр назначений на обходы

На странице отображается список всех назначений:
- **Студент** - кто назначен на обход
- **Корпус-Подъезд** - за какой подъезд отвечает
- **Дата назначения** - когда был назначен
- **Действия** - кнопки для редактирования и удаления

### Назначение студента на обход

1. Найдите раздел "Назначения на подъезды"
2. Нажмите "Назначить студента"
3. Выберите студента из списка
4. Выберите корпус и подъезд
5. Нажмите "Сохранить"
6. Студент будет назначен на обход этого подъезда

**Важно:** 
- Студент должен быть в базе данных
- Студент должен иметь право делать обходы (назначается через модал "Управление правом обхода" (поле `can_do_rounds`))
- Один студент может быть назначен на несколько подъездов

### Удаление назначения

1. Найдите назначение в списке
2. Нажмите "Удалить"
3. Подтвердите удаление
4. Студент будет убран с обхода в данном подъезде

### Просмотр всех назначений
1. Откройте страницу "Назначение на обход"
2. Увидите три раздела: старшие студенты, старосты, назначения на обходы
3. Можно отфильтровать назначения по корпусу или подъезду

## Важные моменты

- Назначение старших студентов и старост доступно только суперадмину
- Староста подъезда назначается на конкретный корпус-подъезд
- Старший студент не привязан к конкретному подъезду, может назначать на любой
- Один студент может быть назначен на несколько подъездов для обходов
- Студент должен иметь право делать обходы (`can_do_rounds = 1`)
- Староста подъезда может только генерировать график дежурств в Telegram боте
- Только старший студент может назначать студентов на обходы через Telegram бота
