# Telegram пользователи (admin_tg_users.html)

## Назначение
Управление пользователями Telegram, которые зарегистрированы в системе. Показывает кто из студентов зарегистрирован в боте, их Telegram данные и статусы.

## Доступ
- **Требуемое право:** `manage_tg_users`
- **Ссылка:** В меню администратора → "Telegram пользователи"

## Что можно делать

### Просмотр списка пользователей
На странице отображается таблица со всеми зарегистрированными пользователями:
- **Telegram ID** - уникальный номер пользователя в Telegram
- **Telegram username** - имя пользователя (@username)
- **ФИО студента** - к какому студенту привязан аккаунт
- **Статус** - зарегистрирован, несоответствие username и не зарегистрирован.

### Поиск пользователя
Можно найти пользователя по:
- **Telegram username** - найдите по @username
- **ФИО студента** - найдите по имени студента

## Как это используется

Эта страница помогает:
- **Проверить регистрацию** - кто из студентов зарегистрирован в боте
