# Отчеты по белью (bed_linen_report.html)

## Назначение
Статистика и аналитика по выдаче постельного белья. Показывает кто получил белье, кто не получил, сводную информацию по периодам.

## Доступ
- **Требуемое право:** `view_reports` или `manage_bed_linen`
- **Ссылка:** В меню администратора → "Отчеты по белью"

## Что можно делать

### Просмотр сводной информации
На странице отображается:
- **Всего выдано** - сколько студентов получили белье
- **Не получили** - сколько студентов еще не получили
- **Процент выдачи** - сколько процентов студентов получили белье

### Фильтрация данных
Можно отфильтровать отчет по:
- **Периоду** - выберите период выдачи белья
- **Дате** - выберите диапазон дат
- **ФИО** - укажите ФИО студента

### Просмотр детализации
В таблице можно увидеть:
- **Студент** - ФИО студента
- **Комната** - где живет
- **Период** - за какой период
- **Статус** - получил или нет


**Дата получения** - когда получил (если получил) можно узнать в карточке студента

## Важные моменты

- Данные берутся из операций сканирования QR-кодов
- Показывается актуальная информация
- Можно фильтровать по разным критериям
- Полезно для контроля выдачи белья
