# Нет доступа (no_access.html)

## Назначение
Страница, которая показывается когда у пользователя нет прав для доступа к странице.

## Когда показывается
- Пользователь пытается открыть страницу, для которой у него нет прав

## Что на странице
- **Сообщение об ошибке** - объяснение почему нет доступа
- **Кнопка "Назад"** - вернуться в админ-панель

## Важные моменты

- Каждая страница проверяет права перед показом
- Если прав нет - показывается эта страница
- Обратитесь к администратору если нужен доступ
