# Управление комнатами (admin_manage_rooms.html)

## Назначение
Справочник всех комнат в общежитии. Можно создавать комнаты, редактировать их параметры, управлять вместимостью.

## Доступ
- **Требуемое право:** `manage_rooms`
- **Ссылка:** В меню администратора → "Управление комнатами"

## Что можно делать

### Просмотр комнат
На странице отображается список всех комнат:
- **Корпус** - номер корпуса
- **Подъезд** - номер подъезда
- **Комната** - номер комнаты
- **Вместимость** - сколько человек может жить
- **Занятость** - сколько человек сейчас живет
- **Категория** - тип комнаты (если настроено)
- **Действия** - кнопки для редактирования и удаления

### Добавление новой комнаты
Добавление комнаты возможно только через Excel файл

### Редактирование комнаты
1. Найдите комнату в списке
2. Нажмите "Редактировать"
3. Измените нужные параметры:
   - Вместимость
   - Категорию
   - Исключить из дежурств (комната не будет учитываться при создании графика дежурств)
4. Нажмите "Сохранить"

### Удаление комнаты
1. Найдите комнату в списке
2. Нажмите "Удалить"
3. Подтвердите удаление

**Важно:** 
- Нельзя удалить комнату, если в ней живут студенты

## Как это используется

Комнаты используются в системе для:
- **Размещения студентов** - при размещении выбирается комната
- **Графиков дежурств** - комнаты распределяются по дежурствам
- **Отчетов** - можно смотреть отчеты по комнатам
- **Расчета оплаты** - сумма зависит от количества проживающих в комнате

## Важные моменты

- Комната определяется комбинацией: корпус + подъезд + номер комнаты
- Вместимость влияет на расчет оплаты
- Комнаты можно исключить из графиков дежурств
- При размещении студента система автоматически учитывает занятость комнаты
