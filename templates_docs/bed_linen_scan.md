# Сканер QR-кодов для белья (bed_linen_scan.html)

## Назначение
Сканирование QR-кодов студентов для автоматического учета выдачи постельного белья. Работает через камеру.

## Доступ
- **Требуемое право:** `scan_qr` или `manage_bed_linen`
- **Ссылка:** В меню администратора → "Сканер QR-кодов"

## Как использовать

### Подготовка
1. Откройте страницу на устройстве с камерой (можно подключить)
2. Разрешите доступ к камере, если браузер спросит
3. Убедитесь, что есть активный период выдачи белья

### Сканирование QR-кода

**Через камеру**
1. Нажмите кнопку "Запустить сканер"
2. Наведите камеру на QR-код студента
3. Дождитесь автоматического распознавания
4. Результат появится на экране

### Что происходит после сканирования

1. Система проверяет QR-код
2. Находит студента в базе данных
3. Проверяет, можно ли выдать белье (есть ли активный период, не получил ли уже)
4. Если все хорошо - отмечает выдачу белья
5. Показывает результат на экране и воспроизводится звуковой сигнал

### Результаты сканирования

**Успешно:**
- "Белье выдано студенту [ФИО]"
- Появляется информация о студенте
- Операция сохраняется в базе

**Ошибки:**
- "QR-код не найден" - код не распознан или не является кодом для выдачи белья
- "Студент не найден" - код не соответствует ни одному студенту
- "Белье уже выдано" - студент уже получил белье в этом периоде
- "Нет активного периода" - администратор не создал период выдачи белья
- "QR-код истек" - код был создан более 5 минут назад

## Особенности работы

### QR-коды для белья
- Создаются студентом через Telegram бота
- Действительны 5 минут
- Одноразовые (после использования нельзя использовать снова)
- Привязаны к конкретному студенту

### Периоды выдачи белья
- Администратор создает периоды (дата начала и окончания)
- Белье можно выдавать только в активный период
- Один студент может получить белье только один раз за период

## Решение проблем

### Камера не работает
- Проверьте разрешения браузера на доступ к камере
- Попробуйте другой браузер

### QR-код не распознается
- Убедитесь, что QR-код для выдачи белья

### Ошибка "Нет активного периода"
- Обратитесь к администратору
- Администратор должен создать период выдачи белья
- Период должен быть активным (текущая дата между началом и концом периода)

## Важные моменты

- Сканирование работает только при наличии активного периода выдачи белья
- QR-коды действительны 5 минут с момента создания
- Один студент может получить белье только один раз за период
- После успешного сканирования операция сохраняется в базе данных
- Для работы требуется доступ к камере устройства
- Результаты сканирования отображаются на экране и сопровождаются звуковым сигналом
