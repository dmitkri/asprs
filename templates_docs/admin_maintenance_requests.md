# Заявки на ремонт (admin_maintenance_requests.html)

## Назначение
Управление заявками студентов на ремонт и обслуживание. Можно просматривать заявки, менять их статусы, добавлять комментарии.

## Доступ
- **Требуемое право:** `manage_rooms`
- **Ссылка:** В меню администратора → "Заявки о поломках"

## Что можно делать

### Просмотр заявок
На странице отображается таблица со всеми заявками:
- **Номер заявки** - уникальный номер
- **Студент** - ФИО студента, который подал заявку
- **Комната** - где проблема (корпус-подъезд-комната)
- **Описание** - что нужно сделать
- **Статус** - новая, в работе, выполнена
- **Исполнитель** - кто взял заявку в работу
- **Дата создания** - когда заявка была создана
- **Действия** - кнопки для работы с заявкой

### Фильтрация заявок
Можно отфильтровать заявки по:
- **Статусу** - все, новые, в работе, выполненные
- **Номеру заявки** - найдите по номеру

### Просмотр деталей заявки
1. Найдите заявку в таблице
2. Кликните на заявку
3. Увидите полную информацию:
   - Данные студента
   - Комната
   - Описание проблемы
   - Статус
   - История изменений
   - Комментарии

### Взять заявку в работу
1. Найдите новую заявку (статус "Новая")
2. Нажмите "Взять в работу" или "Изменить статус"
3. Выберите статус "В работе"
4. (Опционально) Добавьте комментарий
5. Сохраните

### Добавить комментарий
1. Найдите заявку
2. Нажмите "Добавить комментарий" или "Редактировать"
3. Введите комментарий (например: "Вызван сантехник, приедет завтра")
4. Сохраните
5. Комментарий появится в истории заявки

### Закрыть заявку
Когда работа выполнена:
1. Найдите заявку
2. Нажмите "Закрыть" или "Изменить статус"
3. Выберите статус "Выполнена"
4. Добавьте комментарий (опционально)
5. Сохраните
6. Заявка будет закрыта

### Удалить заявку
1. Найдите заявку
2. Нажмите "Удалить"
3. Подтвердите удаление

**Важно:** Удаление необратимо, лучше закрывать заявки, а не удалять.

## Статусы заявок

- **Новая** (new) - заявка только что создана студентом
- **В работе** (in_progress) - заявка взята в работу
- **Выполнена** (completed) - работа выполнена, заявка закрыта

## Как студенты создают заявки

1. Студент открывает Telegram бота
2. Нажимает "Подать заявку"
3. Описывает проблему (например: "Протекает кран в раковине")
4. Отправляет
5. Заявка появляется в системе со статусом "Новая"

## Процесс обработки заявки

1. **Студент создал заявку** - появляется в системе со статусом "Новая"
2. **Администратор видит заявку** - в списке новых заявок
3. **Берет в работу** - меняет статус на "В работе"
4. **Выполняет работу** - заявка в работе
5. **Закрывает заявку** - меняет статус на "Выполнена", добавляет комментарий (опционально)

## Важные моменты

- Каждая заявка имеет уникальный номер
- Заявки можно фильтровать по разным критериям
- История изменений сохраняется
- Комментарии помогают отслеживать прогресс
- Студент может видеть статус своей заявки в боте
