# Управление группами (admin_manage_groups.html)

## Назначение
Управление учебными группами студентов. Группы используются для фильтрации студентов, экспорта данных и организации информации.

## Доступ
- **Требуемое право:** `edit`
- **Ссылка:** В меню администратора → "Управление группами"

## Что можно делать

### Просмотр списка групп
На странице отображается таблица со всеми группами:
- **ID** - уникальный номер группы
- **Название** - название группы (например: "К0709-23/3")
- **Дата создания** - когда группа была добавлена
- **Дата обновления** - когда группа последний раз редактировалась
- **Действия** - кнопки для редактирования и удаления

### Добавление новой группы
1. Нажмите кнопку "Добавить группу" (обычно в верхней части страницы)
2. В открывшемся окне введите название группы
3. Нажмите "Сохранить"
4. Группа появится в списке

**Примеры названий групп:**
- К0709-23/3

### Редактирование группы
1. В таблице найдите нужную группу
2. Нажмите кнопку "Редактировать" в строке группы
3. В открывшемся окне измените наименование
4. Нажмите "Сохранить"

### Удаление группы
1. В таблице найдите нужную группу
2. Нажмите кнопку "Удалить"
3. Подтвердите удаление

**Важно:** 
- Если группа используется студентами, удаление может быть ограничено
- Проверьте, что группа не нужна перед удалением

## Как это используется

Группы используются в системе для:
- **Фильтрации студентов** - можно отфильтровать студентов по группе в главной таблице
- **Экспорта данных** - можно экспортировать всех студентов из конкретной группы
- **Организации данных** - удобно работать со студентами по группам
- **Отчетов** - можно создавать отчеты по группам

## Важные моменты

- Название группы должно быть уникальным (нельзя создать две группы с одинаковым названием)
- Группы можно редактировать в любое время
- При удалении группы студенты не удаляются, просто у них убирается группа
