# Несовершеннолетние студенты (admin_minors.html)

## Назначение
Работа с несовершеннолетними студентами. Позволяет ускорить работу дежурных администраторов.

## Доступ
- **Требуемое право:** `manage_minors`
- **Ссылка:** В меню администратора → "Несовершеннолетние"

## Что можно делать

### Просмотр несовершеннолетних студентов
На странице отображается список всех несовершеннолетних:
- **ФИО** - полное имя студента
- **Комната** - где живет студент
- **Обход** - отметка вечернего обхода с указанием времени
- **Заявление** - заявление об отсутствии в средстве размещения

### Фильтрация списка
Можно отфильтровать студентов по:
- **Корпусу** - выберите корпус

## Особенности работы с несовершеннолетними

### Автоматическое определение
- Система автоматически определяет несовершеннолетних по дате рождения

### Обходы несовершеннолетних
- Для несовершеннолетних студентов проводятся вечерние обходы
- Обходы фиксируются в системе
- Можно посмотреть историю обходов для каждого студента по дате

## Важные моменты

- Несовершеннолетние определяются автоматически по дате рождения
- Данные синхронизированы с основным списком студентов
- При редактировании студента в основном списке, данные обновляются и здесь
