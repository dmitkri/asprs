# Управление получением белья (bed_linen_manage.html)

## Назначение
Управление периодами выдачи постельного белья студентам. Можно создавать периоды, когда студенты могут получить белье, и отслеживать кто получил.

## Доступ
- **Требуемое право:** `manage_bed_linen`
- **Ссылка:** В меню администратора → "Управление получением белья"

## Что можно делать

### Создание периода выдачи белья
1. Нажмите "Создать период" или "Добавить период"
2. Укажите:
   - **Дата начала** - с какого числа можно получать белье
   - **Дата окончания** - до какого числа можно получать белье
3. Нажмите "Создать"
4. Период появится в списке и станет активным в указанные даты

**Важно:** 
- В один момент времени может быть только один активный период
- Студенты могут получить белье только в активный период
- Один студент может получить белье только один раз за период

### Просмотр периодов
На странице отображается список всех периодов:
- **Период** - даты начала и окончания
- **Статус** - активен, завершен или запланирован
- **Дата создания** - когда был создан
- **Действия** - удаление периода

## Как это работает

1. **Администратор создает период** - указывает даты начала и окончания
2. **Период становится активным** - студенты могут получать белье
3. **Студент получает QR-код** - через Telegram бота
4. **Администратор сканирует QR** - через сканер QR-кодов
5. **Система отмечает выдачу** - студент получил белье в этом периоде
6. **Студент не может получить еще раз** - до следующего периода

## Важные моменты

- Один активный период в один момент времени
- Студент может получить белье только один раз за период
- Выдачу можно отметить через сканер
- История выдачи сохраняется в базе данных
