Настройка Telegram User Bot

Настройте User Bot для отправки сообщений от имени вашего аккаунта Telegram

Инструкция по настройке
  1. Получите API ID и API Hash:
    • Перейдите на https://my.telegram.org/apps
    • Войдите в свой аккаунт Telegram (используйте номер телефона)
    • Создайте новое приложение:
      • Укажите название приложения (любое, например "Audit Bot")
      • Укажите короткое имя (любое, например "audit")
      • Выберите платформу (Desktop)
      • Оставьте URL пустым
    • После создания вы получите API ID (число) и API Hash (строка)
  2. Установите зависимости (если еще не установлены): 
    pip install pyrogram tgcrypto
  3. Заполните форму ниже:
    • Введите полученные API ID и API Hash
    • Введите номер телефона в формате +79991234567
    • Нажмите "Сохранить настройки"
  4. Проверьте подключение:
    • Нажмите кнопку "Проверить подключение"
    • При первом подключении в консоли сервера появится запрос на ввод кода подтверждения
    • Код придет в Telegram (в приложение Telegram на вашем телефоне)
    • Введите код в консоль сервера
    • Если включена двухфакторная аутентификация, введите пароль
  5. Готово! После успешной авторизации сообщения будут отправляться от имени вашего аккаунта.
Важно: Файл сессии (telegram_user_session.session) содержит данные для авторизации. Не передавайте его третьим лицам и не добавляйте в репозиторий.
