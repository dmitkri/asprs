## Аутентификация

### Административные API

Большинство административных API используют сессионную аутентификацию:

1. Выполните POST запрос на `/admin` с `username` и `password`
2. После успешного входа устанавливается Flask session cookie
3. Все последующие запросы автоматически используют эту сессию

### Студенческие API

Студенческие API (`/api/student/*`) используют HMAC-аутентификацию:

1. Получите `STUDENT_API_SECRET_KEY` из переменных окружения
2. Для каждого запроса:
   - Создайте Unix timestamp: `timestamp = int(time.time())`
   - Вычислите токен: `HMAC-SHA256(API_SECRET_KEY, timestamp + path + method)`
   - Добавьте заголовки:
     - `X-API-Token`: вычисленный токен
     - `X-Timestamp`: timestamp
